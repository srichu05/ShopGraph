# ShopGraph Processed Dataset Documentation

## 1. Overview & Source
This directory contains the cleaned, normalized, and graph-consistent JSONL files generated by `scripts/preprocess.py` from the raw Amazon Reviews '23 (`Musical_Instruments`) dataset.

- **Raw Sources**:
  - `data/raw/meta_Musical_Instruments.jsonl` (213,593 raw products)
  - `data/raw/Musical_Instruments.jsonl` (3,017,439 raw reviews)
- **Target Destination**: Ingested directly into Neo4j via `scripts/ingest_neo4j.py`.

---

## 2. Processed Files & Schemas

### 2.1 `products.jsonl`
Canonical product records keyed by `parent_asin`.
```json
{
  "id": "B01M4HO6RK",
  "title": "Pearl Export Lacquer EXL725S/C249 5-Piece New Fusion Drum Set...",
  "average_rating": 4.2,
  "rating_count": 22,
  "price": 399.0,
  "price_currency": "USD",
  "raw_price": "399.0",
  "brand_id": "brand_pearl",
  "main_category": "Musical Instruments",
  "category_id": "Musical Instruments > Drums & Percussion > Drum Sets & Set Components > Drum Sets",
  "features": ["Item may ship in more than one box...", "P930 Demonator Pedal..."],
  "description": ["Introducing the best selling drum set..."],
  "image_url": "https://m.media-amazon.com/images/I/51QYyZgky-L._AC_.jpg",
  "details": {"Item Weight": "33 pounds", "Color": "Honey Amber"}
}
```
- `id`: Canonical product identifier (`parent_asin`). Never child variant ASIN.
- `price`: Cleaned float or `null`. **Missing prices remain NULL, never 0.0 or 'free'**.
- `brand_id`: Deterministic normalized brand identifier (links to `brands.jsonl`).
- `category_id`: Canonical full breadcrumb path of the leaf category (links to `categories.jsonl`).

### 2.2 `categories.jsonl`
Canonical category taxonomy nodes.
```json
{
  "id": "Musical Instruments > Guitars > Electric Guitars > Solid Body",
  "name": "Solid Body",
  "level": 3,
  "parent_id": "Musical Instruments > Guitars > Electric Guitars",
  "path": ["Musical Instruments", "Guitars", "Electric Guitars", "Solid Body"]
}
```
- `id`: Canonical full path string. Crucial because 72 category labels in the dataset occur under multiple distinct parent paths (e.g., 'Bags & Cases' occurs under 7 parents). Using the full path prevents invalid category collapsing.
- `name`: Leaf display label.
- `level`: Depth in the hierarchy (`0` for root).
- `parent_id`: Canonical path of the parent category, or `null` for root. Enables `[:SUB_CATEGORY_OF]` hierarchy.

### 2.3 `brands.jsonl`
Normalized brand and storefront entities.
```json
{
  "id": "brand_fender",
  "name": "Fender",
  "raw_store": "Visit the Fender Store"
}
```
- `id`: Deterministic slug (`brand_<clean_name>`).
- `name`: Clean brand name stripped of "Visit the ... Store" or "Brand: ...".

### 2.4 `reviews.jsonl`
Normalized review interaction records.
```json
{
  "id": "rev_90f6c8765031e6b79f31",
  "user_id": "AE57MRF2R2ALCC6H5WQLFKT7KSSA",
  "product_id": "B01MRV9Z1Y",
  "variant_asin": "B00GKOJC5Y",
  "rating": 5.0,
  "title": "Attractive & distinguishable",
  "text": "My Telecaster looks great in this beauty...",
  "timestamp": 1641411629725,
  "verified_purchase": true,
  "helpful_votes": 0
}
```
- `id`: Deterministic 20-character hash ID: `rev_<sha256(user_id|parent_asin|asin|timestamp|rating)[:20]>`.
- `product_id`: Matches `Product.id` (`parent_asin`).
- `variant_asin`: Preserves the specific purchased child ASIN evaluated in this review.
- `timestamp`: Review publication timestamp in millisecond Unix epoch. **Never interpreted as a purchase or order date**.
- `verified_purchase`: Boolean from Amazon verification. When `true`, enables `(:User)-[:PURCHASED]->(:Product)`.

## 3. Transformations & Normalization Applied

1. **Duplicate Review Filtering**:
   - Reviews are hashed across canonicalized content fields: `user_id`, `parent_asin`, `asin`, `rating`, `timestamp`, `title`, `text`.
   - Redundant duplicate rows are dropped on first occurrence.
   - Legitimate multiple reviews submitted by the same user for the same product at *different timestamps* (e.g., long-term updates or separate variant configurations) have distinct hashes and are preserved.
2. **Missing Price Nullness**:
   - Products without price or with non-numeric pricing retain `price: null`.
   - Strictly avoids converting nulls to `$0` or "free".
3. **Category Path Canonicalization**:
   - Categories are generated dynamically by traversing each product's breadcrumb array.
   - Self-contained referential hierarchy ensures every subcategory points to an existing parent category.
4. **Brand Store Cleaning**:
   - Strips boilerplate e-commerce prefixes/suffixes to merge store variations into clean brand entities.

## 4. Sampling Behavior & Graph Consistency

The preprocessing pipeline supports two operational modes:

### Sample Mode (`--mode sample`)
- Designed for rapid local development and environments with node limits (e.g. Neo4j Aura Free tier: 200,000 node cap).
- Default targets: `--sample-products 10000` and `--sample-reviews 50000`.
- **Review-Dense Stratified Sampling Strategy**:
  1. **Pass 1 (Pre-scan)**: Rapidly counts review frequencies across all 3,017,439 raw reviews to build a product review-density index.
  2. **Pass 2 (Product Stratification)**: Selects products with review count >= 3 (relaxing to >= 2 only if needed), while enforcing a strict per-department cap (`sample_products // num_departments`, e.g., max 833 per department). This guarantees **100% of products have reviews** and **99.5% have >= 3 reviews** while preserving broad category and brand diversity across 34 Amazon departments.
  3. **Pass 3 (Streaming Review Selection)**: Streams reviews matching selected products with a dynamic per-product cap (default: ~6 reviews/product) to prevent a single blockbuster product from monopolizing the 50,000-review quota.
- **Graph Consistency Guarantee**:
  - Sampled products are selected across diverse departments with high review activity.
  - Reviews are strictly filtered to only those matching selected products.
  - Users are strictly derived from retained reviews.
  - Brands and Categories are strictly restricted to selected products (including all ancestor paths).
  - **Zero orphan nodes or edges** are created.

### Full Mode (`--mode full`)
- Processes 100% of the 213,593 metadata items and 3,017,439 reviews in a streaming, memory-efficient pass.
- Eliminates in-memory buffering of products; streams directly to disk.

## 6. Reproducibility

To regenerate the processed files from raw data:

```bash
# Generate review-dense development sample (10,000 products, ~50,000 reviews):
python scripts/preprocess.py --mode sample --sample-products 10000 --sample-reviews 50000

# Or process complete dataset (213k products, 3M reviews):
python scripts/preprocess.py --mode full
```
